# SkillSwap

SkillSwap is a free, student-to-student way to get help with a difficult course topic or trade a skill with someone on campus. It is designed for university students on a tight budget who need a quick, friendly way to find peer support between classes.

## Run it

Open `index.html` in a modern web browser. There is no build step, package installation, server, or framework required. Posts are stored in the browser's local storage on the device where they were created.

## What it does

- Choose a tailored Looking for Help or Providing Help path, then post a request or tutoring offer with one or more required weekday/time availability blocks.
- Add an optional skill swap, then browse student posts and filter by topic, format, swap, or free help. Your posts are marked in the community list.
- Browse eight example student posts.
- Highlight compatible peer posts after submitting a request or offer.
- Start a pre-written message, copy the message or contact, or open an email request from a post with immediate action feedback.
- Delete posts created on the current device.

The example posts and any posts you create are local to your browser; this demo does not have a shared campus backend. Posts saved before structured availability was added remain visible with a reminder to confirm their earlier schedule.
